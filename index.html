01

PART 1 · 내 브랜드 콘텐츠 정리

제작한 글, 사진, 카드뉴스, 영상 파일을 다시 찾기 쉽게 모읍니다.

이론

콘텐츠 포트폴리오란?

브랜드를 알리기 위해 만든 소개글, 홍보 이미지, 카드뉴스, 상세페이지, 블로그 글, 숏폼 영상을 종류별로 모아둔 자료입니다.

콘텐츠활용 채널파일 예시
브랜드 소개블로그·SNS 프로필brand_intro.txt
홍보 이미지인스타그램product_photo.png
카드뉴스인스타그램cardnews_01.png
상세페이지온라인 홍보 페이지product_detail.pdf
블로그 글네이버 블로그blog_post.txt
숏폼 영상릴스·쇼츠brand_video.mp4

컴퓨터 화면 따라 하기: 폴더 정리

  1. 바탕화면의 빈 곳을 마우스 오른쪽 버튼으로 클릭합니다.
  2. 새로 만들기 → 폴더를 누릅니다.
  3. 폴더 이름을 내브랜드_AI마케팅_결과물로 작성합니다.
  4. 안쪽에 01_브랜드소개, 02_홍보이미지, 03_카드뉴스, 04_상세페이지, 05_블로그, 06_홍보영상, 07_SNS게시글 폴더를 만듭니다.
  5. 기존 파일을 알맞은 폴더로 이동합니다.
파일이 없다면 지금 비워 두어도 괜찮습니다. AI가 실제로 만들지 않은 파일을 있다고 표시하지 않도록 하세요.
실습 결과: 브랜드 콘텐츠 관리표 1개 + 정리된 폴더 구조
02

PART 2 · SNS 채널별로 재활용하기

같은 소재라도 채널에 따라 글의 길이와 전달 방법이 달라집니다.

이론

원소스 멀티유스(One Source Multi Use)

하나의 원본 콘텐츠를 네이버 블로그, 인스타그램, 유튜브 쇼츠에 맞는 여러 결과물로 바꾸는 방법입니다.

채널특징만들어 볼 것
네이버 블로그정보와 상세 설명제목·본문·사진·CTA
인스타그램시각적 관심 유도후킹 문장·릴스 문구·해시태그
유튜브 쇼츠짧은 영상 중심영상 제목·설명·CTA

내 브랜드 콘텐츠 하나로 다양하게 활용하기

블로그: 상품·서비스의 특징을 자세히 설명
인스타그램: 사진·영상에 짧은 후킹 문장 추가
쇼츠: 15~30초의 핵심 메시지와 행동 유도 문구 작성

실습 순서

  1. 10~11차시에서 만든 대표 콘텐츠 하나를 정합니다.
  2. 대표 콘텐츠의 주제·핵심 메시지를 확인합니다.
  3. 아래 프롬프트를 복사하여 ChatGPT 또는 Gemini에 입력합니다.
  4. 세 채널용 결과를 비교하고 사용할 문장을 선택합니다.
  5. 완성한 결과를 07_SNS게시글 폴더에 저장합니다.
실습 결과: 블로그·인스타그램·쇼츠 게시용 문구 각 1개
03

PART 3 · SNS 게시 전 점검하기

실제 업로드 전에 정보·권리·개인정보를 확인합니다.

이론

게시 전 꼭 확인하는 7가지

항목확인 내용
상품 정보가격·구성·재료·사양이 정확한가?
서비스 정보위치·영업시간·예약 방법이 정확한가?
이미지·영상실물과 다르게 표현되지 않았는가?
고객 후기실제 고객의 확인 가능한 후기인가?
저작권사진·영상·음원을 사용할 권리가 있는가?
개인정보고객 얼굴·번호 등이 허락 없이 나오지 않는가?
광고 표현검증되지 않은 효능·혜택을 주장하지 않는가?
광고 문구를 AI가 생성했다고 해서 사실 확인이나 저작권 점검이 생략되지는 않습니다. 게시 전 본인이 직접 확인해야 합니다.

인스타그램 릴스 따라 하기

  1. 인스타그램에 로그인합니다.
  2. 만들기(+) → 릴스를 선택합니다.
  3. MP4 파일을 선택하고 미리보기를 확인합니다.
  4. 게시글과 해시태그를 붙여넣습니다.
  5. 커버, 공개 범위, 필요한 고지 및 게시 설정을 확인합니다.
  6. 게시 또는 초안 저장을 선택합니다.

유튜브 쇼츠 따라 하기

  1. 유튜브에 로그인합니다.
  2. 만들기 → 동영상 업로드를 선택합니다.
  3. 세로형 MP4 영상을 선택합니다.
  4. 제목·설명·시청자층·공개 범위를 설정합니다.
  5. 미리보기를 확인하고 게시 또는 비공개 저장합니다.
계정이나 기기에 따라 메뉴 이름이 조금 다를 수 있습니다. 계정이 없거나 게시가 부담스러우면 게시 직전까지 실습한 뒤 초안으로 저장하세요.
SNS 게시 화면 — 설명용 재구성
① 영상 선택② 제목③ 설명④ 공개 설정⑤ 저장 / 게시
미리보기 확인 → 게시
